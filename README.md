Short description
TubeScript Studio helps creators and developers quickly produce video scripts using purpose-built templates, a live editor, and one-click exports. Create outlines, auto-generate sections, collaborate with teammates, and export to Markdown or Google Docs. Free to use — premium features planned (templates & integrations).

Features
- Fast templates for intros, stories, hooks, CTAs
- Live editor with section reordering and version history
- Export to Markdown / Google Docs / Copy
- Developer-friendly: TypeScript codebase and examples

Getting started
1. Live demo: open the demo at https://tubescript-studio.vercel.app/
2. Local: `git clone https://github.com/Troublez905/TubeScript-Studio.git && npm ci && npm run dev`
